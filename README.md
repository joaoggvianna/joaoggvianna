## Projetos em destaque

### [Cataglifo — Aprendizado por reforço em Minecraft](https://github.com/cataglifo/cataglifo-project)
**TCC em desenvolvimento, realizado em equipe.** Investigação de como um agente pode aprender a navegar e interagir com um ambiente tridimensional baseado em Minecraft, com experimentos de aprendizado por reforço.

- Modelagem do ambiente, estados, ações e recompensas
- Estudo de métricas para acompanhar a evolução do agente
- Integração entre experimentos do agente e o ambiente do jogo

`Python` `PyTorch` `Reinforcement Learning` · **Em desenvolvimento**

### [Voluntiva — Gestão de voluntariado](https://github.com/joaoggvianna/Voluntiva)
Projeto acadêmico em equipe para conectar ONGs a voluntários e facilitar a gestão de ações sociais, inscrições e participação.

Minha atuação está concentrada em **levantamento de requisitos, modelagem e documentação**, com apoio na definição do protocolo de comunicação da aplicação.

- Estruturação dos requisitos e regras de negócio
- Modelagem da aplicação e documentação técnica
- Apoio na definição do protocolo próprio sobre TCP

`Python` `FastAPI` `PostgreSQL` `TCP` · **Em desenvolvimento**

### [PokéIndex — Explorando APIs com Python](https://github.com/joaoggvianna/pokeindex)
Projeto de estudo desenvolvido para praticar consumo de uma API REST pública. A aplicação consulta dados de Pokémon pela [PokéAPI](https://pokeapi.co/) e apresenta informações no terminal.

- Consumo de API REST com Python
- Manipulação de respostas JSON
- Exercício de lógica e tratamento de dados

`Python` `Requests` `REST API` · **Projeto de aprendizado**
